# Site para Empresa de Climatização

Demonstração de um site moderno e responsivo para uma empresa do ramo de ar-condicionado e climatização.

Este projeto foi desenvolvido para meu portfólio, com o objetivo de demonstrar habilidades em desenvolvimento front-end, design de interfaces e criação de experiências digitais que ajudam empresas a apresentar seus serviços e facilitar o contato com potenciais clientes.

## Prévia

**Demonstração online:** https://lively-shortbread-7c35dc.netlify.app/

## Funcionalidades

- Layout responsivo para computadores, tablets e celulares;
- Design moderno voltado para o segmento de climatização;
- Seções para apresentação dos serviços;
- Menu de navegação adaptado para dispositivos móveis;
- Seção de perguntas frequentes;
- Botões de contato e chamadas para ação pelo WhatsApp;
- Rolagem suave entre as seções;
- Animações sutis;
- Respeito às preferências de acessibilidade para redução de movimento.

*As funcionalidades devem ser conferidas na versão final do projeto.*

## Como executar o projeto localmente

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/hvac-website-demo.git
```

Entre na pasta do projeto:

```bash
cd hvac-website-demo
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O terminal exibirá o endereço local para acessar o site pelo navegador.

## Gerar a versão de produção

Para gerar os arquivos otimizados para publicação, execute:

```bash
npm run build
```

Os arquivos gerados ficarão disponíveis na pasta `dist/`.

Para visualizar a versão de produção localmente, execute:

```bash
npm run preview
```

## Objetivo do projeto

Este é um projeto independente de portfólio, desenvolvido para demonstrar habilidades em criação de sites e desenvolvimento front-end, com foco em empresas de serviços locais.

O site é uma demonstração conceitual e não representa o site oficial de uma empresa real.

## Personalização

O projeto pode ser adaptado às necessidades de uma empresa real, incluindo identidade visual, informações sobre os serviços, dados de contato, imagens e outras funcionalidades.
